# Совместимость платы и безопасная проверка

## Для какой платы подходит

Сборка предназначена для камер на SoC семейства **Ingenic T23/T23N** с MIPS/XBurst-архитектурой и загрузкой Linux 3.10.x.

На данный момент подтверждено только то, что ядро успешно компилируется. Совместимость конкретной платы считается подтвержденной только после проверки:

- маркировки SoC;
- объема и типа RAM;
- SPI NOR/NAND flash;
- UART boot log;
- сенсора камеры;
- Wi‑Fi-чипа;
- GPIO/reset/power enable;
- способа загрузки U-Boot.

## Перед снятием или отключением SPI-flash

Сначала предпочтительна полностью обратимая проверка через UART и SD.

1. Снять полный дамп штатной flash.
2. Сохранить несколько копий и SHA-256.
3. Записать маркировку микросхемы и ее напряжение питания.
4. Сохранить `printenv` U-Boot и boot log.
5. Не стирать и не перезаписывать штатную flash до успешной загрузки с SD.

Физическое снятие микросхемы flash имеет смысл только как диагностический шаг, если плата не позволяет изменить порядок загрузки иначе. После снятия нужно проверить, продолжает ли BootROM/U-Boot искать SD-карту. Без схемы платы нельзя считать этот метод безопасным по умолчанию.

## Что получить из U-Boot

```text
version
printenv
bdinfo
mmc list
part list mmc 0
help fatload
help ext4load
help bootm
```

## Предлагаемая разметка SD

| Раздел | Размер | FS | Назначение |
|---|---:|---|---|
| p1 BOOT | 128 MiB | FAT32 | uImage, boot config |
| p2 ROOTFS | 1 GiB | ext4 | Linux root filesystem |
| p3 DATA | 256 MiB | ext4 | настройки, update, persistent data |
| p4 RECORDINGS | остальное | ext4 | видео, события, снимки |

Фактические offset'ы и параметры загрузки нужно привязать к `printenv` конкретной камеры.

## Первый запуск

Цель первого теста — загрузить `uImage` с SD в RAM и выполнить `bootm`, не изменяя штатную flash.
