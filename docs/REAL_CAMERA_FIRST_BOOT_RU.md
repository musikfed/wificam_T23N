# Первый настоящий запуск T23N с SD — тест от 2026-11-02 (RU)

> **Статус испытания:** на реальной камере с профилем
> \`galayou_g2_t23n_sc2336_atbm6012bx\` обнаружены Wi-Fi и SSH.
> В роутере — устройство \`wificam\`, IP \`192.168.1.55\`; в терминале
> Thingino уже показал баннер и потребовал изменить пароль \`root\`.
> Пока не подтверждены \`/dev/mmcblk0p2\`, камера SC2336, RTSP, PTZ,
> snapshot, отдельный PegineLab Web UI. **Не объявлять весь образ проверенным
> только потому, что появился SSH.**

## 1. Тестовые логины и порты (только наша отладочная сборка)

| Сервис | URL / команда | Логин | Начальный пароль |
|---|---|---|---|
| Thingino SSH (Dropbear) | \`ssh root@192.168.1.55\` | \`root\` | \`root\` до первого изменения |
| Thingino Web | \`http://192.168.1.55/\` или \`https://192.168.1.55/\` | \`root\` | \`root\` до первого изменения |
| **PegineLab WIFICAM** | **\`http://192.168.1.55:8090/\`** | \`admin\` | \`Wificam12345\` (тест) |
| Thingino camera/API | \`http://192.168.1.55:8080/\` | штатный Thingino | отдельная служба, **не** PegineLab |

У другой камеры IP может отличаться — искать его в роутере DHCP.
Адрес \`:8090\` набирается именно с \`http://\`, не \`https://\`.
Установленный root-пароль после его смены больше **не** \`root\`;
он относится к Thingino/SSH, но **не** к отдельному PegineLab \`admin\`.

Эти логины и пароли **публичны только для аппаратной диагностики**.
Не использовать их для домашнего постоянного доступа, гостевой сети,
интернета и финального релиза. Сменить \`root\`, PegineLab \`admin\`
и перевыпустить API-ключ Thingino, если он был показан на скриншоте.

## 2. Windows PowerShell — первый SSH

\`\`\`powershell
ssh root@192.168.1.55
\`\`\`

В первый раз SSH может спросить о ключе удалённого хоста.
Убедись, что IP соответствует камере в роутере, затем ответь \`yes\`.

На строке \`root@192.168.1.55's password:\` введи **начальный**
пароль \`root\`, если его ещё не меняли. Ввод скрыт, символы не
показываются — это нормально.

На экране появится примерно:

\`\`\`text
It's your first login.
You are required to change your password!

Password:
\`\`\`

**ВАЖНО: этот второй \`Password:\` просит уже НОВЫЙ пароль \`root\`,
а не старый \`root\`.** В upstream Thingino это скрипт
[\`overlay/etc/profile.d/chpasswd\`](https://github.com/themactep/thingino-firmware/blob/24ec28c7457686ff733132e580267d6a95308c80/overlay/etc/profile.d/chpasswd)
с последовательностью:

\`\`\`text
Password:      ← придумай НОВЫЙ пароль root (не root)
Confirm:       ← точно повтори новый пароль
Password updated.
\`\`\`

Скрипт не принимает пустой пароль и слово \`root\`. Два ввода должны
совпадать. Не копируй/показывай новый пароль в чат, фотографии, shell
history или репозитории. После изменения сохраняй его у себя —
следующий SSH-вход будет уже с ним. **Не отключай обязательную смену
пароля**, даже в тестовом образе.

Открытая ранее Thingino-страница
\`/config-webui.html?force_password_change=1\` — **штатная**
Thingino Web UI. На ней тоже требуется изменить пароль \`root\`.
Не путать с независимым веб-сервисом PegineLab на \`:8090\`.

## 3. Безопасная read-only проверка после успешной смены пароля

Уже внутри терминала камеры (\`#\`):

\`\`\`sh
# Какое ядро и rootfs реально загружены?
cat /proc/cmdline
cat /proc/mounts | grep mmcblk

# Поднялась ли наша независимая WIFICAM Web UI?
ls -l /usr/share/wificam-web/index.html
grep '^WEB_PORT=' /etc/wificam/wificam.conf
netstat -lnt 2>/dev/null | grep -E ':80 |:443 |:8080 |:8090 '
ps | grep '[h]ttpd'

# Если :8090 не отвечает — прочитать ошибки (ничего не меняет)
tail -n 40 /var/log/wificam-httpd.log 2>/dev/null
\`\`\`

**Признак загрузки с SD:** в аргументах ядра или реальном mount
нужно подтвердить \`root=/dev/mmcblk0p2\` / \`/dev/mmcblk0p2\`
(\`ext4\`). Баннер Thingino и работа Wi-Fi сами по себе этого
ещё не доказывают.

Если на \`:8090\` меню не открылось, сначала сохранить результаты
этих команд. Не перезапускать все \`httpd\` и не форматировать SD
вслепую. Типовые ошибки и userspace-исправления есть в
[FIRST_BOOT_SSH_RU.md](FIRST_BOOT_SSH_RU.md). Пересборка ядра для
обычной ошибки webroot/порта не требуется.

## 4. Что проверять затем

1. Наша Web UI на \`http://192.168.1.55:8090/\` показывает **PegineLab**, а не Thingino; тестовый вход \`admin / Wificam12345\`.
2. Thingino на HTTP/HTTPS отдельно открывается после смены пароля \`root\`.
3. Сообщить вывод \`/proc/cmdline\` и \`/proc/mounts\` без секретов (не показывать \`/etc/shadow\`, \`wpa_supplicant.conf\`, API tokens).
4. Проверить доступность камеры/снимка/потока, затем PTZ и звук на реальном оборудовании. Эти пункты пока **не подтверждены**.

**Изменение пароля на работающей камере не меняет исходный \`.img\` на Huananzhi/GitHub.
Если снова перезаписать SD исходным тестовым образом, повторная первичная
смена может понадобиться.**
