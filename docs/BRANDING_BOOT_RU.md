# PegineLab: логотип и загрузочная заставка

Эта функция находится в экспериментальной ветке `mymarrchWFcam`.

## Что добавлено

- логотип PegineLab в Web UI;
- favicon/avatar;
- баннер PegineLab в документации;
- оригинальный 7-секундный 8-bit/chiptune джингл;
- ранний init-скрипт `S05peginelab-boot` для framebuffer при его наличии;
- поздний `S94peginelab-audio` для микрофонно-динамического тракта Raptor;
- короткая заставка PegineLab в Web UI камеры на `:8090`, не зависящая от `/dev/fb0`;
- копия логотипа и джингла на BOOT-раздел SD.

## Принцип

Заставка **не должна задерживать загрузку камеры**. Скрипт запускает изображение/звук в фоне и сразу отдаёт управление следующим init-скриптам.

Картинка показывается только если есть `/dev/fb0` и установлен `fbv` либо `fbi`.

Исходный WAV остаётся для хранения; генератор также формирует `boot-jingle.s16le` (16 кГц, 16 бит, моно). `S94peginelab-audio` после старта камерных служб передаёт PCM через `/usr/sbin/play -s -r 16000 -`, используя штатный динамик T23N. Старт не блокирует запуск системы. Результат пишется в `/var/log/wificam-boot-audio.log`; код завершения воспроизведения ещё не подтверждает, что звук физически слышен.

На плате без framebuffer (`/dev/fb0`) заставка не может появиться «на экране камеры»; она показывается в браузере при открытии собственной WIFICAM веб-страницы.

Если framebuffer или аудиоустройство отсутствуют, загрузка продолжается без ошибки. Сборщик и инспектор образа YadroKreator дополнительно проверяют наличие Web UI, WAV, native PCM и `S94` внутри ext4; физическое воспроизведение проверяется после прошивки.

## Настройки

В `/etc/wificam/wificam.conf`:

```text
BOOT_SPLASH=1
BOOT_SOUND=1
BOOT_BRANDING_SECONDS=7
```

Чтобы полностью убрать звук:

```text
BOOT_SOUND=0
```

## Размер

В архиве два варианта мелодии: WAV — mono PCM 8-bit, 11025 Hz, около 77 KiB; native `s16le` — mono PCM 16-bit, 16000 Hz, ровно 224000 байт. Это специально сделано лёгким для embedded-системы.

Исходник генератора: `tools/generate_boot_jingle.py`.
