# WIFICAM T23N 0.2_test — подготовка испытательного SD-образа (RU)

Это **не выпуск прошивки и не подтверждение работы оборудования**. Версия 0.1_test остаётся эталоном для отката.

## Условие начала

- Исправление проверки Wi-Fi должно находиться именно в ветке `mymarrchWFcam`, которую YadroKreator может собирать. Ни `main`, ни эталонный `Thingino/thingino-t23-sd.bin` не переписывать.
- YadroKreator должен иметь исправленный выбор артефакта: только `out/candidate-sd/` либо `out/private-sd/` текущего задания, рядом файл `.sha256`. Старый Git-tracked `Thingino/0.1_test` нельзя выдавать за новый кандидат.
- На сервере должны быть закреплённый checkout Thingino, доступ к GitHub, один свободный build slot и достаточное место на ext4. Не прерывать процесс вручную при отсутствии реального сбоя.
- `local/wifi.env` является **необязательным**: при наличии он обрабатывается как секрет, сохраняется только в приватном образе; без него компиляция не должна требовать пользовательский WPA2-файл. Wi-Fi в таком образе потребуется настраивать штатным методом Thingino после первого запуска.

## На Ubuntu Huananzhi (пользователь, не root)

```bash
cd /1tbdisk/PegineLab/projects/YadroKreator

# Проверить рабочее дерево, не стирать локальные изменения:
git status --short
bash scripts/project-control.sh status

# Если панель была остановлена и сборки не идут:
bash start.sh
```

Только после принятия исправления в YadroKreator `main` можно безопасно выполнить проверяемое обновление его кода:

```bash
bash deploy.sh --check
bash deploy.sh --apply
```

Команда обновления *не* компилирует новую прошивку. Не запускать `bootstrap.sh` поверх живого развертывания и не удалять базы/кеши ради обновления.

Открыть в разрешённой LAN/VPN панели `http://192.168.0.100:62404/` → **WIFICAM T23N / Сборки** → профиль `t23n_sd` → ветка `mymarrchWFcam` → **WIFICAM_WEBRTC=0** (легковесный тест; необязательно выбирать Helper, если его preset не установлен) → **Новая сборка**.

Фабрика закрепляет текущий Git SHA, запускает Thingino/Buildroot с `PUBLISH=0`, сохраняет кандидат в изолированном job. Компиляция не пишет на SD и не меняет аппаратную камеру. Для каждого задания смотреть статус, конец лога и SHA.

## Скачивание и запись на microSD

Только для `status=success` и файла `out/candidate-sd/thingino-t23-sd.bin` или `out/private-sd/thingino-t23-sd.bin`:
1. «Проверить образ перед записью SD»: SHA256 + MBR + MSPL на LBA34 + FAT16 BOOT/uImage с LBA2048 + ext4 ROOTFS с LBA34816. Никаких предупреждений.
2. «Артефакты» → «Скачать образ .img». Это тот же raw-диск, расширение изменено лишь для удобства.
3. На Acer/Windows: вставить именно **microSD камеры** в кардридер; проверить размер/идентификатор; Rufus в DD/raw режиме или balenaEtcher **Flash from file → Select target → Flash → Validate**. Записать с LBA0. Не форматировать Linux/ext4 после записи.
4. Выключить питание камеры, вставить новую карту, включить. Не заменять единственную рабочую `0.1_test` карту.

## Физическая приёмка по порядку

1. `cat /proc/cmdline` должен показать `root=/dev/mmcblk0p2`. Проверить монтирование ext4.
2. Wi-Fi DHCP и SSH Dropbear, сменить заводские тестовые пароли; сохранить постоянный способ восстановления.
3. Проверить `http://CAMERA_IP:8090/`, авторизацию и настоящий JSON `/cgi-bin/api` (не исходник `#!/bin/sh`). При отказе CGI порт 8090 должен оставаться закрыт.
4. RTSP ch0/ch1 и кадры SC2336; звук микрофона (реальная audio track), затем негромкий тест динамика через rac/play.
5. PTZ в обе стороны с STOP, IR-cut/ночной режим, холодный повторный старт, стабильность и задержки.
6. После аппаратного PASS проверить на Acer/CORE Hombo3: камера как глаза/уши/голос; YOLO/OpenCV и VLM работают **в ходе диалога**, не внутри 64 MB RAM T23N.

**Не объявлять `0.2_test` проверенной** при наличии лишь успешного CI, файла или SSH.

## Важно для приватности

Если образ содержит Wi-Fi конфигурацию, не публикуйте `.img`, `.bin`, `rootfs.ext2`, `out/private-sd/` или содержимое `wifi.env` в GitHub. Загрузка через незащищённый HTTP вне собственной VPN/LAN недопустима. Пользовательский `PUBLISH=1` во время аппаратных тестов запрещён.
